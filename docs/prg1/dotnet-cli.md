
# PRG1 – Podstawowe komendy .NET CLI

| Polecenie | Przykład użycia | Opis |
|---|---|---|
| `dotnet --version` | `dotnet --version` | Wyświetla wersję używanego .NET SDK. |
| `dotnet --list-sdks` | `dotnet --list-sdks` | Wyświetla zainstalowane wersje .NET SDK. |
| `dotnet new list` | `dotnet new list` | Wyświetla dostępne szablony projektów. |
| `dotnet new console` | `dotnet new console` | Tworzy aplikację konsolową w bieżącym katalogu. |
| `dotnet new console -n MyApp` | `dotnet new console -n MyApp` | Tworzy aplikację konsolową o nazwie MyApp. |
| `dotnet restore` | `dotnet restore` | Przywraca zależności projektu. |
| `dotnet build` | `dotnet build` | Kompiluje projekt. |
| `dotnet run` | `dotnet run` | Uruchamia projekt. |
| `dotnet clean` | `dotnet clean` | Usuwa pliki wygenerowane podczas kompilacji. |

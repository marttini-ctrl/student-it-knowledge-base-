Przykładowa procedura pracy

  1. Zsynchronizuj lokalną gałąź main.
  2. Utwórz nowy branch.
  3. Zmodyfikuj pliki.
  4. Wykonaj commit.
  5. Wyślij branch na GitHub.
  6. Utwórz Pull Request.
git switch main
git pull --ff-only origin main
git switch -c feature/zmiana
git add .
git commit -m "Opis zmian"
git push -u origin feature/zmiana
